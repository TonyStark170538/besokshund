# Min Hund Du och Jag 🐾

A warm, accessible website for **Marie and her therapy dogs**, designed to introduce their work and explain how social service dogs can support people in healthcare, education, and care environments.

🌐 **Live website:** https://besokshund.vercel.app/

---

## About the Project

**Min Hund Du och Jag** is a Scandinavian-inspired wellness website created for a social service / therapy dog practice.

The goal was to create a digital experience that feels:

- Warm
- Calm
- Trustworthy
- Professional
- Human-centered
- Easy to navigate

Instead of using a typical clinical or corporate visual style, the website combines **Scandinavian minimalism with organic wellness aesthetics** to reflect the emotional and supportive nature of therapy-dog work.

The website introduces Marie and her dogs while guiding visitors through their story, services, and the role of social service dogs.

---

## Design Direction

### Soft Scandinavian Wellness

The visual identity is based on **warm minimalism with organic softness**.

The design uses generous whitespace, rounded shapes, soft shadows, natural colors, and subtle motion to create a calm experience.

The design intentionally avoids:

- Excessive visual clutter
- Aggressive animations
- Harsh colors
- Overly clinical layouts
- Unnecessary decorative elements

The website is designed to feel welcoming before the visitor even starts reading.

---

## Typography

The typography combines a friendly display typeface with a highly readable body font.

- **Poppins** — headings and display text
- **Inter** — body copy and interface elements

The typography hierarchy was designed to remain readable across desktop and mobile screen sizes.

Design Details

The interface uses subtle organic elements to reinforce the theme.

Signature Elements
Soft wave dividers
Rounded cards
Paw-print accents
Warm color transitions
Gentle shadows
Staggered layouts
Dog-focused visual storytelling

Dog profile cards are designed to give each dog an individual personality while maintaining a consistent visual system across the site.

Motion & Interaction

Animation is intentionally subtle.

The goal is to make the interface feel alive without distracting from the content.

Interactions include:

Gentle fade-in animations
Small slide-up entrance effects
Subtle card elevation on hover
Soft scale transitions
Color and shadow transitions
Small decorative micro-interactions

Most transitions use approximately 300–400ms easing.

The design avoids flashing, aggressive movement, and unnecessary animation.

Accessibility

Accessibility was treated as part of the design rather than an afterthought.

The website focuses on:

Readable typography
Strong text contrast
Keyboard-friendly navigation
Clear interactive states
Descriptive image alternative text
Responsive layouts
Sensory-friendly animation
Mobile-friendly interaction

The visual system was designed around a minimum target of 4.5:1 contrast for normal text.

Responsive Design

The website is designed to work across:

Desktop
Laptop
Tablet
Mobile

Layouts, typography, spacing, and interactions adapt to smaller screens rather than simply shrinking the desktop design.

Particular attention was given to:

Touch targets
Readable text sizes
Content spacing
Navigation
Stacked card layouts
Mobile-friendly calls to action

Development Approach

The project was developed from the initial visual concept through implementation and refinement.

The process included:

Defining the visual direction
Creating the color and typography system
Designing the page structure
Building reusable UI components
Implementing responsive layouts
Adding subtle interactions and animations
Reviewing accessibility
Testing the experience across screen sizes
Deploying the finished website

The focus was not only on making the website visually attractive, but on creating a consistent system that supports the actual purpose of the site.

Project Goals

The main goals were to:

Create a trustworthy online presence
Make the therapy-dog work easy to understand
Introduce the dogs in a personal way
Build emotional connection without sacrificing professionalism
Make contacting the service straightforward
Create a calm and accessible browsing experience
Design Philosophy

The design should support the story, not compete with it.

The dogs, the people behind the service, and the work they do are the most important parts of the experience.

The interface therefore acts as a frame: warm enough to create emotional connection, structured enough to communicate professionalism, and restrained enough to let the content remain the focus.
